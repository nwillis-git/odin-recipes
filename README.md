# odin-recipes
TOP HTML Foundations Project: Recipes

All recipes are taken from allrecipes.com

This is the first project in The Odin Project Foundations course, testing application of foundational HTML skills.
The assignment is to create a website which displays three different recipes on different pages.
To accomplish this, I applied various text tags, hyperlinks, embedded images, and file directory management using the terminal. I also learned about version control using both git and github through this project.
